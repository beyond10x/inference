Speech-to-text, LLMs, text-to-speech and native speech models behind one set of Rust contracts, composed into streaming pipelines that are checked before they run.

The problem: every voice or language product is wired to the models it launched with.

  • The provider's SDK leaks into the application: its event names, audio formats, way of interrupting, tool-call shape.
  • Changing provider, or running a model yourself, means rewriting the pipeline.
  • "Streaming" means different things across providers, and a demo cannot tell you which one you bought.
  • Interruptions, partial transcripts and tool calls are where conversations break.

WHY IT MATTERS

No lock-in

Changing provider changes a binding, not the application.

Compare providers on latency and usage: 0.6.0

Honest capabilities

Each adapter declares what it can do. A pipeline that needs more is refused before it runs, with an error that names it.

Conversations that behave

Barge-in stops unplayed speech. Provisional words stay provisional. Tools run once, on committed input.

Runs where you need it

Offline with egress denied, or hosted when you opt in.
