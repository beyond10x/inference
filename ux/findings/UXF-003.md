The shared theme draws links without an underline. Inside a paragraph a link differs from the text
around it only by colour, which fails WCAG 1.4.1 (axe `link-in-text-block`, serious) in both themes.

Cost: S (one rule in `website/src/css/custom.css`). The shared theme of `@beyond10x/docs-system` sets
the link style for every site; the rule here fixes this site only.

Fix: links inside paragraphs, list items, table cells and quotes of a page are underlined.
