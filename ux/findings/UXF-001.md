The navbar carries no search field on any page. A reader who knows a name (`INFERENCE_LLAMA_SERVER_URL`,
`ReuniteError`) and not the page it is on has only the sidebar.

Frequency: every page, every gating state. Cost: M (a dependency and a theme entry).

Fix: the local search theme `@easyops-cn/docusaurus-search-local` 0.55.3, indexing the docs only. The
index is built with the site; no service is called. Two defects came with it and are fixed in the same
change: its key hint had a contrast of 1.3:1 (axe `color-contrast`), and the opened field is a
`combobox` without `aria-controls` (axe `aria-required-attr`, critical), which
`website/src/client-modules/search-aria.ts` sets from its `aria-owns`. The layout contract walks the
navbar by keyboard before axe runs on the landing page and Getting started, so axe sees the opened
field.
