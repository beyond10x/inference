## Decision

On 2026-11-23 the operator asked to select stories from the review of release 0.31.0 and ship them,
one wave per repository. That request is the approval of this wave. Four units were implemented and
committed on their own branches before the wave opened, each from origin/main at 0.32.0 (62991a94):

| unit | story | findings | branch |
|---|---|---|---|
| U1 | story:gate-test-budget-and-planning-skip | 16, 17 | `impl/gate-test-budget-and-planning-skip` |
| U2 | story:live-session-commit-and-close-under-full-ingress | 8, 9 | `impl/live-session-commit-and-close-under-full-ingress` |
| U3 | story:duplex-ledger-correctness | 10, 12, 14 | `impl/duplex-ledger-correctness` |
| U4 | story:cascade-recipe-usage, story:speak-recipe-keeps-text-on-commit | 3 | `impl/recipe-usage-and-speak-commit` |

Decisions taken in the units: the agent test of sends at close runs 1,000 rounds at 16 sessions at
once; no global timeout of 120 s on the test step until CI has measured the step; the slow lane
also runs when `crates/inference/src` changes.

## Breaking

U3 moves `FrameLengthMismatch` from `inference-tts` to `inference-audio` and adds
`SessionError::FrameLength` to `inference-duplex`, and updates every caller in this repository in
the same change.

## Integration

Branch `wave/2026-11-23-next`. U1 is merged first, so the merged tree is gated with the gate it
introduces, then U2, U3 and U4, each with `--no-ff`. `CHANGELOG.md` keeps every unit's Unreleased
line under its heading, `Breaking` first; generated files are regenerated with `inference-docs
generate`, never merged by hand.

## Gates

Once, on the merged tree, with the rustc `rust-toolchain.toml` pins: `task check-source` or its
parts; the nextest run (60 s kill per test) of `inference`, `inference-facade`, `inference-duplex`,
`inference-audio`, `inference-tts`, `inference-pipeline`, `inference-runtime`, `inference-docs`,
and of the duplex adapters `inference-openai`, `inference-aws`, `inference-elevenlabs`,
`inference-deepgram` and `inference-testkit`; `task test-slow` once; `ess specify validate --path
ess`; `inference-docs generate --check`; `aep plan artifact validate`. The whole-workspace test run
is not started on the shared host.

## Commits authorised

The merges of the four unit branches into the wave branch, the store commits that open and close
the wave, fixes of merge fallout, and one pull request to `main` through the bot route. No merge of
that pull request by this wave's run, no release, no tag, no version bump.
