## Decision

The operator's coordinator approved this wave on 2026-11-03, under the operator's standing grant
for waves, commits, pull requests and releases through the bot route: deliver release 0.10.0 as
one wave covering the gaps a downstream adopter found in the `inference-openai` `RealtimeClient`
and `LiveClient` of 0.9.0. Its words: "G1-G6 are required. G7-G9 go in only if each is small and
safe; otherwise file each as a draft story and say so." and "Do not merge, tag or release before
my go."

The coordinator named these stories as the wave and asked for them to be walked to `active`; the
moves below run on its word.
