## Checked and found sound

- Duplex ledger (`crates/inference-duplex/src/ledger.rs`, read in full): close/fail ordering (settle, cancel/fail the response in progress, record at end, deliver held, then the end event), identity reuse refusals, liveness bound with `ProviderFrame::read_in_part`, truncation of completed/cancelled responses (as `duplex.yaml:910-912` says), `wall_ms` arithmetic; `Response`/`SpeechSession`/`ReceivedSessionEvent` transitions match `duplex.yaml`.
- Runtime: `Run`/`NodeInstance` transitions equal `graph.yaml:570-600` line for line; `EdgeQueue` under every policy has no lost wakeup (waker registered under the lock, woken after state change), `drop_stale_epochs` discards only lower epochs of the same producer; `GuardedSender` restores a sequence only when it still holds it; controller steps check before moving and `wind_down` covers every non-terminal instance; `drain_layer` is a join over one layer; `Recorder::without_identities` slices on ASCII-checked boundaries; the egress watch parses `/proc` rows with `Option` throughout.
- Hosted adapters: OpenAI's server-event state machine (duplicate `response.created`, id-less `response.done`, output after cancel refused), PCM16/24 kHz/ms conversions and `audio_end_ms`, `Fields`-based JSON reads, `Zeroizing` credential with `set_sensitive`, no key in any Debug/Display/URL (`request_url` refuses `?`); AWS `redact`, decoder `Option` reads, event-stream framing left to the SDK, no secret in errors; ElevenLabs `ws://` refused off loopback, carry of odd PCM bytes, bounded close; both claims records equal the code and are held by `claims_record` tests.
- Local adapters: sherpa and whisper hash checks (sha256 of every file, lowercase against lowercase constants, before the native library opens anything); FFI object ordering and `Send + Sync` of the wrappers; playout `Queue::next`/`played_index`/`prune` for up- and down-sampling; capture ring release/acquire pairing; llama-server bridge waker hand-off and cancel guard; `adapter_revision` 0.16.0 in every record.
- Contract crates: G.711 against the ITU tables, polyphase resampler indices and `u128` position carry, `samples_at`/`data_len` overflow bounds, `Quantity` invariant on constructor and wire, exact-fraction ms sums, every `expect`/index preceded by its check, `checked_add` on sequences, outcome orders against `tools.yaml`/`policy.yaml`, no UTF-8 byte slicing.
- Facade: session commands' refusal orders against `session.yaml`, lock order inbox → sessions → pricer with no await under a lock, cancel racing the run's end idempotent under `finished`, usage counted before the cut, cost arithmetic in `i128` with overflow refusal, unknown stays unknown.
- Tests sampled: apart from N36 and N37, every sampled assertion names a literal or a state an alternative implementation would violate.
