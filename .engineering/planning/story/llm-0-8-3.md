## Context

`llm` 0.8.3 (2026-10-21) exports `b10x-llm-credentials::AnonymousResolver`, the resolver for a
protocol client built for an anonymous binding such as a keyless local server, refusing every
resolve with `SecretError::Missing`. `adapters/inference-llama-server/src/lib.rs:260-270` keeps a
private copy (`Anonymous`, refusing with `SecretError::InvalidReference`) whose doc says it goes
once `llm` exports one.

The same release adds `b10x-llm-http::require_tokio_runtime`: every protocol client and exchange
now refuses to run outside a Tokio runtime instead of failing inside the transport. That does not
give a client that can be polled outside a runtime, so the adapter's runtime bridge (each turn on
a thread of its own through `llm`'s `BlockingModel`, crate documentation "The runtime bridge")
stays; its closing sentence, "the bridge goes when `llm` offers a client that can be polled
outside a runtime", stays true.

`b10x-llm-chat` 0.8.3 also reads llama-server's `timings` object for its counters, so a
llama-server stream without a usage chunk reports input, cached input and output tokens where it
reported them unknown before.

## Planned scope

- Every `llm` dependency moves from tag 0.8.0 to 0.8.3: the workspace `llm-core` and the
  llama-server adapter's `llm-blocking`, `llm-chat`, `llm-credentials` and `llm-http`; `Cargo.lock`
  for those packages only.
- The adapter hands `AnonymousResolver` to its client; the private `Anonymous` goes.
- Any test or fixture of the adapter whose usage expectations change with the `timings` reading is
  updated, each change named in the closing note; a test pins that a stream carrying `timings` and
  no usage chunk reports its tokens as provider-reported.
- `AGENTS.md`'s rule on the `llm` repository names 0.8.3.

## Acceptance

`cargo tree -p inference-llama-server` lists every `b10x-llm-*` package at 0.8.3 and no 0.8.0, the
adapter's source holds no resolver of its own, and its tests pass offline with a llama-server
stream without a usage chunk reporting its tokens as provider-reported.

- With a local `llama-server` present, the ignored live tests of the adapter pass.
