## Outcome

The inference documentation site is a Docs System (Docusaurus) site under `website/`, deployed
from `main` by the `Documentation validation` and `Documentation site` workflows, with its
derivable pages (crate list, adapter capability matrix, error kinds, status data) generated by the
`inference-docs` crate and drift-checked by `task check`. The mdBook under `site/` is gone.

## Acceptance

- `cargo run -p inference-docs -- generate --check` exits 0 on the tree and exits 1 after any
  generated file is edited by hand (test `every_generated_file_is_current_in_this_tree`).
- Every `shipped` status item names an evidence test `path::function` that exists and is not
  ignored; the generator refuses one that is missing or ignored.
- Each hosted adapter's capability claims equal its JSON record (a test in each adapter crate), and
  the adapter reference page is generated from those records.
- `npm --prefix website run build` exits 0; `task check` exits 0.
- The landing names its audience and shows the smallest real run with output generated by calling
  the example's library.
- No page states as shipped anything that is not on `main`.
